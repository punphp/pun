# Highlight

Marks the one phrase a headline is about. `sticker` boxes a single word in `zap` with an outline, `pop-sm` and `tilt-word` (-2deg), so it looks stuck on. `marker` runs a skewed `zap` highlighter under a short phrase.

- Props: `variant` (`sticker` | `marker`), `tone` (`gum` swaps the sticker fill), `children`.
- One per headline, one or two words for `sticker`, up to three for `marker`. Never on body copy.
