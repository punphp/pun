# DocsPage

The docs layout: a `card` top bar with wordmark, ⌘K search and version Tag; a `paper-2` sidebar (mono group labels, the current page as a `zap` sticker, the 512px mascot at the bottom); a 68ch article; an "On this page" rail.

- Article order: breadcrumb, `h1` command name, one-sentence `lede`, a terminal CodeBlock, at most two Callouts, `h2` sections, flag tables, previous/next cards.
- Tables use the sticker frame with `pop` and dashed `hairline` rows; flag names in mono.
- Content comes from the repo's README and docs/, word for word where possible.
