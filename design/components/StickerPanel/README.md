# StickerPanel

The big outlined panel with the `dot-grid` texture: home for the mascot in the hero, and for any hero-sized visual. `radius-xl`, `pop-lg`, `lilac` by default.

- Props: `tone` (`lilac` | `zap` | `gum` | `mint`), `className`, `style`, `children` (the visual; it sits above the texture).
- Text on it is `ink`. Pin a Burst to its top-right corner and a mono tag to its lower-left, each half off the edge.
