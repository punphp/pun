# LandingPage

The marketing page, built only from the bundle, top to bottom: nav (wordmark, four links, `sm` zap Install), hero (Pill, `display` headline with one sticker Highlight, lede, InstallBox, two Buttons; mascot on a StickerPanel with a `zap` ring, a Burst and a loose mono tag), Ribbon, ToolCard row, the race (kicker, h1, `mega` 51×, Benchmark), parity (two CodeBlocks around a "=" Burst), a `gum` StickerPanel CTA, mono footer.

Use this order for the real site. Sections are 96px (`space-24`) apart; the page clips horizontal overflow for the Ribbon.
