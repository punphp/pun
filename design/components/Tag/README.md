# Tag

A tiny uppercase status chip: `stroke-thin` outline, mono 10.5px, one word. On cards it sticks out over the top edge (ToolCard does this for you).

- Props: `tone` (`mint` | `zap` | `lilac` | `gum` | `plain`), `children`.
- Status words and their tones are fixed: `ready` mint, `building` zap, `designed` lilac, `next` plain, `new` gum. The word carries the meaning; colour only repeats it.
