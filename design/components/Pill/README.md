# Pill

The eyebrow above a hero or section headline: one short fact in `code-sm` mono on a `card` pill with a `pop-sm` shadow. Lead with a `Tag` (`tag` prop, `mint` by default) for a version or status, or leave it out to get the `gum` dot.

- Props: `tag`, `tagTone` (`mint` | `zap` | `gum` | `lilac` | `plain`), `children` (the fact).
- One pill per section, max ~40 characters. State a fact the repo can prove ("pun format is Pint-identical"), never hype.
