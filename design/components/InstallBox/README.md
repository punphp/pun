# InstallBox

The one install command on a page: tabs per package manager on `code-bar`, the command on `code-bg` with a `gum` `$`, a `zap` copy button, and the `pop-lilac` shadow that no other element uses.

- Props: `options` (`[{ label, command }]`, one or more), `defaultIndex`.
- Order the tabs composer, curl, brew, npm on PHP pages. Commands are copied exactly from the README; never shorten a URL with an ellipsis in a real page.
- One per page, in the hero or the quickstart.
