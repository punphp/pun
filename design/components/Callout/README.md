# Callout

A boxed aside in docs: lettered tile (`i` note on `lilac`, `✓` tip on `mint`, `!` warn on `zap`), a bold title and one or two sentences in `ink-2`.

- Props: `tone` (`note` | `tip` | `warn`), `title`, `children` (inline `code` is styled).
- At most two per docs page, never two in a row. Warn is for behaviour that changes output or needs PHP installed, not for opinions.
