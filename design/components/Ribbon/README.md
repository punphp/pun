# Ribbon

The slanted scrolling band (`tilt-ribbon`, -1.5deg) of short facts on `ink`, with a `zap` bolt between items and every third item in `lilac`. It bleeds past the page edges, so the page must clip horizontal overflow.

- Props: `items` (4 to 8 facts, two or three words each, lowercase).
- One per page, between the hero and the first section. Motion stops under `prefers-reduced-motion`.
