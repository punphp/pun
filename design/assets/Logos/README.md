# Logos

Interim marks until the mascot is final. All are fixed-colour SVGs (no `currentColor`), so pick the file for the ground.

- `pun-wordmark.svg`: bolt + hand-built "pun" lettering, `ink` letters. Use on `paper`, `card`, `lilac`, `zap`, `gum` grounds. Minimum width 96px.
- `pun-wordmark-reverse.svg`: the same with `paper` letters. Use on `ink` and on the dark theme's `paper`.
- `pun-bolt.svg`: the bolt alone, `zap` fill with an `ink` outline. Favicons, avatars, bullets in the ribbon. Reads on any ground.
- `pun-appicon.svg`: `lilac` tile, `ink` outline and hard shadow, bolt centred. App and social icons.

Never recolour the bolt, never set "pun" in a font in place of the lettering, never add a tagline inside the lockup.
