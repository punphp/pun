---
title: pun list-files
description: List selected files after applying paths and exclusions.
---

```bash
pun list-files
pun list-files --command analyse
pun list-files --command format
pun list-files -0 app | xargs -0 wc -l
pun list-files --format json
```

Output is sorted, relative to the project root, with one path per line.

## File selection

| Selection | Paths | Exclusions |
| --- | --- | --- |
| Default | `[files] paths`, otherwise the project root | `[files] exclude` |
| `--command format` | Shared paths | Format exclusions, Pint finder rules, and Blade unless enabled |
| `--command lint` | Shared paths | Lint exclusions, Blade, and default excluded directories |
| `--command analyse` | `[analyse] paths`, otherwise shared paths | Analyse exclusions, Blade, and default excluded directories |

Command exclusions include `[files] exclude`. Default excluded directories are `bootstrap/cache`, `build`, `node_modules`, and `storage`.

Path arguments replace configured paths. Outside format, exclusions still apply to explicitly named files. `vendor/` is never listed, though analysis reads it for symbols.

## Options

| Flag | Meaning |
| --- | --- |
| `--command format\|lint\|analyse` | Select a command's file set |
| `-0`, `--zero-terminate` | End each path with a NUL byte instead of a newline, for `xargs -0` |
| `--format json` | Print a JSON array |
| `--config <path>` | Read another pun.toml |

Under a coding agent, the summary line goes to stderr, so stdout stays one path per line and is safe to pipe.

## Example

With this config, the default selection includes `app` and `tests`. The analyse selection includes only `app`:

```toml
[files]
paths = ["app", "tests"]
exclude = ["storage/**"]

[analyse]
exclude = ["tests/**"]
```
