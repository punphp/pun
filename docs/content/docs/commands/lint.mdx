---
title: pun lint
description: Report and fix code rules, with the same diff and written files as Rector, plus Mago's lint rules.
---

```bash
pun lint                 # report, like rector process --dry-run
pun lint --fix           # apply fixes, like rector process
pun lint --fix --format  # fix, then format, in one pass
```

`pun lint` runs Rector's rules natively and matches Rector's diff and written files. Like Rector, `pun lint --fix` doesn't format afterwards; add `--format`, or use [`pun check --fix`](/docs/commands/check).

## Rules

Rules come from Rector and its Laravel, PHPUnit and Pest sets, plus Mago's linter, under Pun's own kebab-case names: `lint.prefer-early-return`, `lint.no-loose-comparison`, `lint.no-unused-ignore`. Which rules run is set by your [preset](/docs/configuration/presets) and add-ons, with per-rule overrides in `pun.toml`:

```toml pun.toml
[lint]
rules.prefer-early-return = "error"
rules.no-loose-comparison = "off"
```

Mago's lint rules are opt-in under `[lint.mago]` and reported as `mago.*`.

## Reading rector.php

Without `pun.toml`, Pun reads `rector.php` directly, so trying Pun needs no changes. [`pun migrate`](/docs/commands/migrate) turns it into `pun.toml`.

Rules with no auto-fix only report. Fixes are marked safe or unsafe, and `--fix` applies safe ones.
