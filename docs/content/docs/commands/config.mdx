---
title: pun config
description: Print the configuration Pun will actually use.
---

```bash
pun config                  # resolved config, as TOML
pun config --format json
pun config --preset psr12   # what a built-in preset resolves to
```

Prints the resolved configuration: the preset's rules plus your `[format.rules]` and `[lint.rules]`, under Pun rule IDs. Use it to check what a change to `pun.toml` did, or to see what a preset contains.
