---
title: pun config
description: Print resolved settings and enabled rules as TOML or JSON.
---

```bash
pun config
pun config --format json
pun config --preset psr12
```

Output uses the same sections as `pun.toml`: `[php]`, `[files]`, `[format]`, `[lint]`, and `[analyse]`.

## Resolved values

| Field | Contents |
| --- | --- |
| Command `rules` tables | Enabled rules after preset, set, group, and rule settings, with levels and options |
| `[[lint.overrides]]` | Path overrides as configured, not applied to a particular file |
| Command `exclude` lists | Shared exclusions plus command-specific exclusions |
| `ecosystems` | Dependencies detected from `composer.lock` |
| `[analyse] switches` | Preset type switches resolved by config; not yet applied by the analysis CLI |
| `[php] version` | Explicit setting, otherwise the lowest version `require.php` allows, otherwise 8.4 |

Disabled rules are omitted. The TOML starts with a comment naming the configuration sources.

## Options

| Flag | Meaning |
| --- | --- |
| `--format toml\|json` | Output format; default `toml` |
| `--config <path>` | Read another config file |
| `--preset <name>` | Resolve a built-in format preset without `pun.toml` |

Resolution does not prove full runtime support for migrated analysis settings. See [analysis limitations](/docs/commands/analyse#configuration).
