---
title: pun analyse
description: Report type errors with the same results as PHPStan and Larastan, including baselines and ignores. It never edits files.
---

```bash
pun analyse          # alias: pun analyze
pun analyse app tests
```

`pun analyse` reports the same errors as PHPStan with Larastan, honours your baseline and ignores, and never edits a file. Larastan's Laravel knowledge (models, relations, facades, container bindings, config) is built in.

## Configuration

`pun migrate` writes this from your `phpstan.neon`:

```toml pun.toml
[analyse]
preset = "strict"
paths = ["app", "tests"]
baseline = "pun-baseline.toml"

[analyse.rules]
"types/missing-iterable-value-type" = "off"
```

There are no levels. An [analyse preset](/docs/configuration/presets#analyse-presets) picks PHPStan's levels in five bands, and rules turn on and off one by one. `pun migrate` expands your PHPStan level into the exact list of rules it ran, so nothing changes on migration day.

## Rule names

Errors carry Pun's own IDs, `analyse/<group>/<name>`: `analyse/undefined/method` rather than `method.notFound`. Silence one with an [ignore comment](/docs/configuration/ignore-comments):

```php
$user->fullName(); // @pun-ignore analyse/undefined/method -- added by a macro
```
