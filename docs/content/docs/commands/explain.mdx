---
title: pun explain
description: Look up a rule by Pun ID or upstream name.
---

```bash
pun explain lint/style/no-alias-function
pun explain style/no-alias-function
pun explain no_alias_functions
```

The command prefix is optional when the name identifies one rule. Upstream names are accepted for lookup, not as aliases in `pun.toml`.

## Output fields

| Field | Meaning |
| --- | --- |
| Rule ID and summary | Pun name and description |
| `group` | Group name and scope |
| `presets`, `sets`, or `preset` | Selections that enable the rule |
| `intent` | `correctness` or `suspicious`, when recorded |
| `fix` | `safe`, `unsafe`, `mixed`, or `none` |
| `fixed by` | Lint rule that can fix an analyse finding |
| `upstream` | Equivalent upstream names and tools |
| `docs` | Source mapping link |

`mixed` fixes are safe where type information proves them safe and unsafe otherwise. `none` means report-only.

An upstream or earlier Pun name prints its current Pun ID before the explanation. Unknown or unsupported names exit 2 with a reason.

The [rule reference](/docs/rules) also lists options and implementation status.
