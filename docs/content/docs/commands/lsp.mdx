---
title: pun lsp
description: One language server for PHP. PHPantom code intelligence plus Pun's formatting, diagnostics and fixes.
---

```bash
pun lsp
```

`pun lsp` is one language server on stdio:

- **Code intelligence** from [PHPantom](https://github.com/PHPantom-dev/phpantom_lsp): completion, hover, definitions, references, symbols and rename.
- **Formatting** exactly like `pun format`, with the project's config and exclusions.
- **Diagnostics** from `pun lint` and `pun analyse`, the same ones the CLI reports, with PHP's exact syntax-error messages.
- **Fix all** as a `source.fixAll.pun` code action.

Config is read at startup: restart the server after editing `pun.toml`. Setup for each editor is in [Editors](/docs/guides/editors).
