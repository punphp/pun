title: Extra rules
description: Opt-in Pun/ rules ported from Mago for Laravel and Pest idioms and redundant code. None is in a preset.
---

Pun adds opt-in `Pun/` rules ported from [Mago](https://github.com/carthage-software/mago) for things PHP-CS-Fixer and Pint don't cover. **None is in any preset**, so default output stays identical to Pint. Enable them in `pun.toml`:

```toml pun.toml
[format.rules]
"Pun/prefer_dedicated_status_assertion" = true
"Pun/prefer_fake_helper" = true
```

Rules marked **risky** can change behaviour; review their diff.

## Laravel

| Rule | Rewrites |
| --- | --- |
| `Pun/prefer_dedicated_status_assertion` | `->assertStatus(404)` → `->assertNotFound()` (25 codes) |
| `Pun/prefer_fake_helper` | `$this->faker` → `fake()` in `*Factory` classes |
| `Pun/prefer_array_validation_rules` | `'required\|string'` → `['required', 'string']` in `rules()` |
| `Pun/no_implicit_model_query` (risky) | `User::where(...)` → `User::query()->where(...)` |
| `Pun/final_controller` (risky) | `class UserController` → `final class UserController` |

## Pest

| Rule | Rewrites |
| --- | --- |
| `Pun/use_specific_expectations` | `->toBe(true)` → `->toBeTrue()`, likewise `false` and `null` |
| `Pun/use_dedicated_expectation` (risky) | `expect(is_array($x))->toBeTrue()` → `expect($x)->toBeArray()` |
| `Pun/use_simpler_expectation` | `expect($a > $b)->toBeTrue()` → `expect($a)->toBeGreaterThan($b)` |
| `Pun/no_only` | removes `->only()` from tests |

## Redundant code and modern PHP

| Rule | Rewrites |
| --- | --- |
| `Pun/no_redundant_isset` | `isset($a, $a['b'])` → `isset($a['b'])` |
| `Pun/no_redundant_literal_return` | `if ($x === null) { return null; } return $x;` → `return $x;` |
| `Pun/no_redundant_nullsafe` | `$user?->name ?? 'Guest'` → `$user->name ?? 'Guest'` |
| `Pun/no_self_assignment` | deletes `$a = $a;` |
| `Pun/prefer_array_spread` (risky) | `array_merge($a, [1], $b)` → `[...$a, 1, ...$b]` |
| `Pun/prefer_explode_over_preg_split` | `preg_split('/, /', $s)` → `explode(', ', $s)` |
| `Pun/prefer_first_class_callable` (risky) | `fn ($x) => $this->m($x)` → `$this->m(...)` |
| `Pun/sensitive_parameter` | adds `#[\SensitiveParameter]` to `$password`, `$token`, `$secret` and API-key parameters |

Each rule ports only the rewrites that keep the code's meaning; the edge cases each one skips are listed in the repository's `docs/MAGO-EXTRAS.md`.
