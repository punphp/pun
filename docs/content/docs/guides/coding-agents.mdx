title: Coding agents
description: Automatic compact output, detection overrides, and machine reports.
---

Pun detects coding agents and uses compact plain text. Check output starts with a summary, followed by findings with project-relative paths:

```
pun check: fail, 1 error, 2 files with fixes (412 checked, 0.21s)
app/A.php format/arrays/syntax, format/tags/blank-line-after-opening
app/B.php lint/style/no-alias-function [fix:unsafe] Master functions shall be used instead of aliases.
app/D.php:2 syntax-error Parse error: syntax error, unexpected token ";" on line 2.
```

Clean runs print only the summary. Lists stop after 20 items; `-v` shows all items and available diffs. Output has no color, progress indicator, or boxes. Exit codes do not change.

`pun migrate` reports the written config and skipped items. `pun config` and `pun list-files` print their summary line on stderr, so stdout stays plain TOML or one path per line.

## Detection and overrides

Detection uses agent-specific environment variables and the `agent-detector` crate. A missing terminal does not enable agent mode. `CURSOR_TRACE_ID` alone does not count; `CURSOR_AGENT` does.

Overrides apply in this order, highest priority first:

| Override | Effect |
| --- | --- |
| `--agent` / `--no-agent` | Force agent output on or off for this run |
| `PUN_AGENT=1` / `PUN_AGENT=0` | Same, from the environment |
| `PAO_DISABLE=1` / `PAO_FORCE=1` | Disable or force agent mode; disable wins |

## Explicit reports

An explicit `--format` takes precedence over automatic compact output. For format, lint, and check, `--format=json` selects PHP-CS-Fixer's JSON and `--format=agent` selects Pint's JSON agent reporter. Neither is Pun's plain-text agent mode.
