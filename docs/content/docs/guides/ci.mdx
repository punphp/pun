---
title: CI
description: Run pun check in CI. One binary, no PHP setup.
---

[`pun check`](/docs/commands/check) formats, lints and analyses in one pass and exits non-zero on any problem, which is all CI needs.

```yaml .github/workflows/style.yml
name: Pun

on: [push, pull_request]

jobs:
  pun:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install Pun
        run: curl -LsSf https://github.com/punphp/pun/releases/latest/download/punphp-installer.sh | sh
      - name: Check
        run: pun check
```

For annotations on the pull request, write a report in a format your CI understands:

```bash
pun format --test --output-to-file=pun.xml --output-format=checkstyle
```

`junit`, `gitlab`, `json`, `xml` and `txt` work the same way.

:::tip[Pre-commit hook]
`pun check --staged` checks only staged files, so a hook stays instant.
:::
