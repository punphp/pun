---
title: Editors
description: Format on save with pun lsp in VS Code, Neovim and PhpStorm.
---

All three run [`pun lsp`](/docs/commands/lsp) as a language server and use it as the PHP formatter.

<Tabs param="editor">
  <Tab title="VS Code">

Install any generic LSP client extension and configure it with:

- command: `pun`
- arguments: `["lsp"]`
- document selector / language: `php`

Then pick that extension as the default formatter for PHP.

  </Tab>
  <Tab title="Neovim">

Neovim 0.11 or newer:

```lua init.lua
vim.lsp.config('pun', {
  cmd = { 'pun', 'lsp' },
  filetypes = { 'php' },
  root_markers = { 'pint.json', 'pun.toml', 'composer.json', '.git' },
})
vim.lsp.enable('pun')
-- format: vim.lsp.buf.format({ name = 'pun' }), e.g. from a BufWritePre autocmd
```

  </Tab>
  <Tab title="PhpStorm">

With the LSP4IJ plugin:

1. Settings › Languages & Frameworks › Language Servers › `+`
2. Name `Pun`, command `pun lsp`
3. Under Mappings › File type, add `PHP`

Reformat Code then goes through Pun.

  </Tab>
</Tabs>

:::note
The server reads `pint.json` and `pun.toml` at startup. Restart it after editing either.
:::
