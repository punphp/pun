Every claim here is reproduced by the harness in the repository (`cargo run -p punphp-harness -- format`), against Pint 1.29.3 and PHP-CS-Fixer 3.95.17.

## Speed

On laravel/framework:

| | Time |
| --- | --- |
| Pint | 190 s |
| Pun, cold | 3.7 s |
| Pun, warm cache | 0.07 s |

That's 51× faster cold, and over 2,700× faster warm.

## Byte-for-byte output

For each project the harness runs Pint on one copy, and `pun migrate` then `pun check --fix` on another, then compares every file. So every run also proves the migration. `differing` must be 0.

| Project | Files | Identical | Differing |
| --- | --- | --- | --- |
| larastan | 725 | 725 | 0 |
| laravel/framework | 3,483 | 3,483 | 0 |
| laravel/laravel | 66 | 66 | 0 |
| laravel/pint | 573 | 573 | 0 |
| pest | 757 | 757 | 0 |
| pinkary | 799 | 799 | 0 |
| pinkary (unformatted copy) | 799 | 799 | 0 |

Exit codes and the machine formats (`--format=json`, `checkstyle`, ...) are compared with Pint's by `scripts/cli-parity.sh`. They match, with one deliberate difference: when Pun couldn't run (a bad `--format`, a report it can't write, a missing path), it exits 2 where Pint exits 1.

Pinkary runs twice: as committed, and as a deliberately unformatted copy where Pint changes 346 files. The same holds with `--preset psr12` on every run.

## Fuzzing

`scripts/fuzz-parity.sh` applies seeded style mutations to real files so Pint has work to do, formats one copy with Pint and one with Pun, and compares every file. On pinkary and laravel/framework, three seeds each, Pint changed 1,763 of 2,196 mutated files, and Pun differed on none.

The full, current tables are in [`context/reports/scoreboard.md`](https://github.com/punphp/pun/blob/main/context/reports/scoreboard.md).
