Pun is a PHP toolchain written in Rust. It reads `pun.toml` and provides these commands:

| Command | Purpose |
| --- | --- |
| [`pun format`](/docs/commands/format) | Fix layout, casing, and spelling |
| [`pun lint`](/docs/commands/lint) | Report code issues and apply fixes with `--fix` |
| [`pun analyse`](/docs/commands/analyse) | Report type errors without editing files |
| [`pun check`](/docs/commands/check) | Run format, lint, and analyse |
| [`pun migrate`](/docs/commands/migrate) | Convert existing tool configs to `pun.toml` |
| [`pun init`](/docs/commands/init) | Create `pun.toml` for a new project |

## Compatibility

Pun ports rules from Pint, PHP-CS-Fixer, Rector, PHPStan, Larastan, and Mago. PHPStan, Larastan, and Rector support is incomplete. The [rule reference](/docs/rules) marks unimplemented rules as Planned.

`pun format` runs layout rules only. Risky and code-deleting Pint fixers are lint rules, so a migrated Pint configuration uses `pun check --fix`. See [parity](/docs/parity) for recorded comparisons and their limits.

PHP checks need no PHP runtime. Blade formatting requires Node.js and Prettier. Some config migrations require PHP and the original tool.
