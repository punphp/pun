---
title: Quickstart
description: Run Pun on an existing Laravel project. It reads your current configs, so there is nothing to set up.
---

Pun reads `pint.json`, `phpstan.neon` and `rector.php` as they are. Install it, then:

<Steps>
  <Step title="Check everything">

```bash
pun check
```

Format, lint and analyse in one pass, sharing one parse. Exits non-zero on any format diff, lint error or analyse error.

  </Step>
  <Step title="Fix what can be fixed">

```bash
pun check --fix
```

Applies safe lint fixes, then formats. It never edits based on analysis.

  </Step>
  <Step title="Only what you touched">

```bash
pun check --dirty        # uncommitted changes
pun check --staged       # staged changes, for a pre-commit hook
pun format --diff=main   # changed since branching off main
```

  </Step>
  <Step title="Move to one config">

```bash
pun migrate --dry-run
pun migrate
```

Writes `pun.toml` from your current configs, with zero behaviour change.

  </Step>
</Steps>

:::tip[Why is the second run so fast?]
Pun caches results per file under `~/.cache/pun`. On laravel/framework, `pun format` takes 3.7 s cold and 0.07 s warm. Use `--no-cache` to check every file.
:::
