## What it does

Annotations in PHPDoc should be grouped together so that annotations of the same type immediately follow each other. Annotations of a different type are separated by a single blank line.

## Options

| Name | Type | Allowed values | Default | Upstream name |
| --- | --- | --- | --- | --- |
| `groups` | `list-of-lists` | Any value of this type | `[["author", "copyright", "license"], ["category", "package", "subpackage"], ["property", "property-read", "property-write"], ["deprecated", "link", "see", "since"]]` | `groups` |
| `skip-unlisted-annotations` | `bool` | Any value of this type | `false` | `skip_unlisted_annotations` |
