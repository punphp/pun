## What it does

PHPUnit assertion method calls like `->assertSame(true, $foo)` should be written with dedicated method like `->assertTrue($foo)`.

## Options

| Name | Type | Allowed values | Default | Upstream name |
| --- | --- | --- | --- | --- |
| `assertions` | `list` | `assertEquals`, `assertNotEquals`, `assertNotSame`, `assertSame` | `["assertEquals", "assertNotEquals", "assertNotSame", "assertSame"]` | `assertions` |
