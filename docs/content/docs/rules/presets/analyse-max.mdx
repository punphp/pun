Explicit and implicit mixed types.

```toml
[analyse]
preset = "max"
```

Ecosystem and target-version settings still apply. Planned rules are not implemented.

This preset covers PHPStan levels 9–10 and includes every lower preset (levels 0–10). Extension rules are included by their mapping preset, not by a PHPStan core level.

Type switches resolved by config, but not yet applied by the analysis CLI:

```toml
[analyse]
union-types = true
nullables = true
explicit-mixed = true
implicit-mixed = true
```
