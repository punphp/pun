## Config translation

Pun reads only pun.toml. `pun migrate` leaves the source config in place. Unported rules and unsupported items are named and skipped, with a request to send a PR. There is no PHP fallback.

Run `pun migrate --from pint`. Pint's risky and code-deleting fixers become lint rules, not format rules.

| pint.json | pun.toml |
| --- | --- |
| `preset: laravel` or `psr12` | `[format] preset = "laravel"` or `"psr12"` |
| `preset: per` or `symfony`, and `@PER-CS` rule sets | Expanded explicit rules over the `empty` format preset |
| `rules` | `[format.rules]` for layout; `[lint.rules]` at `"error"` for code edits |
| Rule options | Pun option names and values, listed on each rule page |
| `in`, `exclude`, `notName`, `notPath` | `[files] paths`; `[format] exclude`, `not-name`, `not-path` |
| `@php-cs-fixer-ignore` | `@pun-ignore-file` with the full format rule ID |
