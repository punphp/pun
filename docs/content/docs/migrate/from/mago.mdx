## Config translation

Pun reads only pun.toml. `pun migrate` leaves the source config in place. Unported rules and unsupported items are named and skipped, with a request to send a PR. There is no PHP fallback.

`pun migrate` detects `mago.toml` but does not translate it yet. It reports the file as unsupported and leaves it untouched. Use the table to select equivalent Pun rules by hand.

| Mago config | Manual Pun equivalent |
| --- | --- |
| Formatter settings | Choose `[format] preset` and explicit layout rules; Mago's printer is not a Pint-compatible preset |
| Linter rule codes | Linked `[lint.rules]` or `[format.rules]` entries |
| Analyzer issue codes | Linked analyse rule IDs, sometimes several per code |
| Exclusions | `[files] exclude`, or exclusions under the matching command |

Analyzer links lead to Mago's analyzer overview: Mago 1.57 has no per-code reference pages. `Pun/*` names identify Pun's existing Mago ports, not separate Mago rule codes.
