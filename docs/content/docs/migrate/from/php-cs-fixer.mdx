## Config translation

Pun reads only pun.toml. `pun migrate` leaves the source config in place. Unported rules and unsupported items are named and skipped, with a request to send a PR. There is no PHP fallback.

Run `pun migrate --from php-cs-fixer`. System PHP reads `.php-cs-fixer.php` or `.php-cs-fixer.dist.php` through PHP-CS-Fixer itself.

| PHP-CS-Fixer config | pun.toml |
| --- | --- |
| `setRules()` and rule sets such as `@PER-CS` | Expanded rules, split between `[format.rules]` and `[lint.rules]` |
| `setRiskyAllowed(true)` | Enabled risky fixers become lint rules at `"error"` |
| Configured options | Pun names and values on the linked rule pages |
| Finder `in()`, `exclude()`, `notName()`, `notPath()` | `[files] paths`; `[format] exclude`, `not-name`, `not-path` |
| Custom fixer classes | Unsupported; named and skipped. Send a PR. |
