## Config translation

Pun reads only pun.toml. `pun migrate` leaves the source config in place. Unported rules and unsupported items are named and skipped, with a request to send a PR. There is no PHP fallback.

Larastan is part of the PHPStan migration: run `pun migrate --from phpstan` on the config that includes `larastan/larastan/extension.neon`.

| Larastan config | pun.toml |
| --- | --- |
| Larastan include | Built-in Laravel checks; no PHP extension dependency at runtime |
| Laravel dependency in composer.lock | Automatic Laravel ecosystem gate |
| Config without the Larastan include | The analyse `laravel` group is off |
| Rule booleans and changed parameters | Rule on/off settings and kebab-case options for each running rule that reads them |
| `ignoreErrors` and `@phpstan-ignore larastan.*` | Pun rule IDs, retaining the original identifier in ignore tables |

Planned checks remain documented here but do not run until ported. The Laravel groundwork is still in progress.
