## Build from source

Requires Rust 1.99 or later and access to the repository. Release packages are not published yet.

```bash
cargo install --locked --git https://github.com/punphp/pun punphp
pun --version
```

From a local checkout, install with:

```bash
cargo install --locked --path crates/pun-cli
```

## Runtime requirements

- Projects must target PHP 8.4 or later. Pun reads the target from `composer.json` unless `[php] version` overrides it.
- PHP checks need no PHP or Node runtime.
- Blade formatting requires Node.js and these project dependencies:

```bash
npm install --save-dev prettier@^3.8.4 prettier-plugin-blade@^3.2.2 prettier-plugin-tailwindcss@^0.8.0
```

- Migrating `.php-cs-fixer.php` or `rector.php` requires PHP and the corresponding tool. For Rector, run `composer install` first.

Continue with the [quickstart](/docs/quickstart).
