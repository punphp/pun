---
title: Installation
description: Install the pun binary with the shell installer, Homebrew, npm or Composer, or build it from source.
---

Pun is one native binary with no PHP or Node dependency. Prebuilt binaries cover Linux x64 and arm64 (glibc and musl) and macOS x64 and arm64.

<Tabs param="install">
  <Tab title="Shell">

```bash
curl -LsSf https://github.com/punphp/pun/releases/latest/download/punphp-installer.sh | sh
```

  </Tab>
  <Tab title="Homebrew">

```bash
brew install punphp/tap/pun
```

  </Tab>
  <Tab title="npm">

```bash
npm install --save-dev @punphp/pun
```

  </Tab>
  <Tab title="Composer">

```bash
composer require --dev punphp/pun
```

The Composer package downloads the native binary on first run.

  </Tab>
  <Tab title="From source">

```bash
cargo install --git https://github.com/punphp/pun punphp --features mago-lint
```

Release builds ship with the `mago-lint` feature, which `pun lint --mago` needs.

  </Tab>
</Tabs>

Check it works:

```bash
pun --version
```

## Next

Pun reads one file, `pun.toml`. In a project that uses Pint today, write it with:

```bash
pun migrate
```
